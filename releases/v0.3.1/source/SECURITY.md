# 安全策略

## 支持的版本

仅最新的正式版本接受安全修复。

## 报告漏洞

请勿在公开 Issue 中披露漏洞细节。请通过 GitHub 仓库的 **Security → Report a vulnerability**（私密安全公告）提交，并尽量包含：

- 受影响的版本和环境；
- 复现步骤或概念验证；
- 潜在影响。

收到报告后会先确认并评估，修复发布后再公开说明。

## 范围说明

- 诊断功能默认只读，不修改系统配置。
- 抓包需要管理员权限，由主程序以 `--capture-host` 参数经 UAC 重新启动自身完成。
- AI 服务 API Key 以 DPAPI（当前用户）加密后存入本地数据库，不写入日志或报告。
- 请勿在 Issue、日志或截图中附带真实凭据、API Key 或未脱敏的内网信息。
