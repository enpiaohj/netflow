# NetFlow v0.3.1

发布日期：2026-09-24

本版本改为按 GPL-3.0 许可证发布，重新组织“关于与环境”页，并修复窗口缩放时的控件自适应问题。

## Added

- **许可证**：按 GPL-3.0 发布；仓库新增 `LICENSE`、`THIRD-PARTY-NOTICES.md`、`SECURITY.md`、`.gitattributes`。
- **设置 → 关于与环境**：按“关于 / 隐私与数据 / 运行环境”组织，显示版本、开发者、源码仓库、许可证；隐私说明如实陈述不收集遥测，唯一可能的对外请求来自用户启用的 AI 分析。

## Changed

- 版本号显示在窗口左上角品牌名右侧，移除左下角版本文字。
- 设置页卡片随窗口宽度拉伸（原为固定 900 宽并靠左）。
- “本机网络”适配器表、“服务与日志”监听端口表改用比例列宽并设最小宽度。
- 集成测试示例配置与默认值改用示例域名 `corp.example.com`；真实环境值仅存于本地 `testsettings.local.json`。
- 文档：用户手册 v1.1、设计变更说明 v1.2；更新 README、CLAUDE.md、根目录 `CHANGELOG.md`。

## Fixed

- 批量任务页在窗口较矮或展开“管理端口包”时，检测结果区被压缩至不可见：改为整页可滚动，结果区保底高度。
- 本机网络适配器表在最小窗口（1100 × 680）下名称、前缀、MAC 等列被截断。
- 设置页抓包引擎检测文案括号重复（“（（版本未输出））”）；TShark 未检测到时句子重复。

## Known Issues

- 自定义场景模板仍保存在 `user-templates.json`，无图形化编辑器。
- CLI 暂不支持源网卡选择与端口包。
- AI 分析仅支持 DeepSeek。
- 动态 RPC 端口（49152–65535）的可达性无法在“检测远程端口”中验证。
- LDAP 绑定与查询、SQL 登录阶段、WinRM HTTP 阶段无法指定源地址，结果中已注明。
- 编译存在 2 条既有警告：`AppLog.cs(30)` CS8604、`PcapngAnalyzer.cs(90)` CS0168。
- 发布产物未做代码签名，首次运行时 Windows SmartScreen 可能给出警告。
- 尚无安装包工程（MSIX 待代码签名证书就绪后评估）。
