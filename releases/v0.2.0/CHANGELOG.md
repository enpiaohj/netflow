# NetFlow v0.2.0

发布日期：2026-09-24

界面体验与多网卡版本：统一控件视觉、优化各页面布局与交互、新增应用图标、**支持多网卡源网卡选择**，并修复快速测试中的若干逻辑问题。诊断核心（判定矩阵、抓包、报告）与 v0.1.0 一致。

## Added

- **多网卡源网卡选择**：顶栏“源网卡”改为下拉（自动 / 各在线网卡，含 VPN 与虚拟网卡）。快速测试、场景诊断、批量任务、持续监测按所选网卡的地址绑定源地址；证据中显示“绑定源地址 x.x.x.x”
  - 按目标协议族取地址；所选网卡已下线或没有同协议族地址时明确报错，不静默回退到系统路由
  - 网卡候选排除回环、IPv4 169.254/16 自动私有地址与 IPv6 链路本地地址；窗口重新获得焦点时刷新，所选网卡下线时恢复为“自动”并提示
  - 持续监测按网卡名在每次采样时取当前地址（网卡换 IP 后仍有效），网卡不可用时该次采样记为未确认
  - 场景诊断的目标解析结果优先选与源地址同协议族的地址
- 应用图标：蓝色渐变圆角底 + 白色 “N” 形流向线（起点节点 → 绿色终点节点），同一份 `NetFlow.ico` 用于 exe 文件图标、窗口与任务栏；图标母版由 `scripts/generate_icon.py` 生成
- 输入框占位提示与字段标签；各数据表格无数据时显示引导文字
- 总览快速入口新增 HTTP/TLS、Ping/路径；入口直接切换到对应测试类型（如“DNS 解析”直达快速测试的 DNS 类型）
- 历史报告：双击记录打开报告
- 主窗口最小尺寸 1080×640

## Changed

- 统一设计系统：输入框（圆角/聚焦高亮）、页签（下划线样式）、表格（浅色表头、整行选中、单元格垂直居中）、分段选择按钮
- 快速测试：先选测试类型再填写参数；端口仅在 TCP/UDP 类型显示；超时、端口等字段增加标签；按类型显示说明
- 抓包分析：参数区改为两行布局（原 11 列挤在一行）；校验错误以红色显示，与进行中的状态提示区分
- 批量任务：持续监测区域高度自适应（原固定 110 高度会裁切内容），移除无效的分隔条
- 历史报告：未选中记录时“打开报告 / 重跑此任务”禁用（原为点击后弹窗提示）
- 服务与日志：目标留空即本机，不再预填机器名
- 场景诊断：模板名称自动换行（原被截断并出现横向滚动条）；空的时间线、空状态行不再占位
- 本机网络：适配器名称列加宽；防火墙“加载规则”按钮移到表格上方
- 证据/分析文本框自身滚动，取消外层 ScrollViewer 嵌套
- 抓包目标、路由查询目标、批量/监测目标等控件不再预填内置测试环境地址，改为占位提示

## Fixed

- **ICMP 探针谎报源地址**：.NET Ping 无法绑定源地址，原实现却把“请求的源地址”写成本次源地址。现改为如实记录限制（“本次由系统路由选择，未使用所选源地址”），并不再写入源地址。LDAP 绑定/查询、SQL 登录阶段、WinRM HTTP 请求阶段同样无法绑定源地址，已同样如实标注（TCP 连通性检查、UDP、DNS、TLS、HTTP、SMTP、SMB、SSH、RDP、NTP 探针照常绑定）
- 快速测试结果表“探针”列对所有类型都显示 `TcpConnect`：现按实际探针类型（Dns / Tls / IcmpPing 等）显示
- DNS / HTTP 类型测试被“名称预解析”提前拦截：域名不存在（NXDOMAIN）等待诊断的情形无法执行，URL 形式的目标解析失败；现仅 TCP/UDP、Ping、NTP 预解析目标
- 非 TCP/UDP 类型被无关的端口校验拦截
- 总览目标输入框把占位文字写入真实文本；改为真正的占位提示
- 源网卡下拉项的自动化名称（读屏）显示为 record 默认文本，已改为网卡显示名

## Known Issues

- 抓包需要 UAC 提权（一次性子进程）；拒绝后仅执行普通探针，界面如实标注；抓包按目标 IP 过滤，暂不随源网卡选择限定抓包网卡
- Ping/路径（ICMP）、LDAP、SQL 登录阶段无法指定源网卡，由系统路由选择（界面与证据均已标注）
- DNS/HTTP 类型及场景诊断中，源网卡按 IPv4 地址绑定（目标为 IPv6 字面量的场景诊断除外）；目标仅解析出 IPv6 时会因协议族不匹配而失败并提示
- 本开发机未加域：Kerberos SSO/机器账户路径仅验证到「显式凭据」级别
- TShark 为用户自装可选组件，未安装时深度解析不可用（内置分析不受影响）
- CLI 为基础版（单探针 + 场景诊断），批量/监测尚未接入，暂无源网卡参数
- 模板编辑为文件级（user-templates.json），无可视化编辑器
- 编译存在 2 条既有警告（非本版本引入）：`AppLog.cs(30)` CS8604、`PcapngAnalyzer.cs(90)` CS0168，计划后续版本清理
- 尚无安装包工程（MSIX 待代码签名证书就绪后评估）；图标已就绪，可直接用于后续安装包
- 仅在 1280×780 及以上窗口尺寸下核对过界面显示
