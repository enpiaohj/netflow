# NetFlow v0.3.2

发布日期：2026-09-24

本版本修复设置页修改默认值后需重启才生效的问题。

## Fixed

- 设置页修改默认抓包方式、最长时长、截断字节数、默认超时、批量并发数后，需重启才对“抓包分析”“快速测试”“批量任务”页生效：现立即生效。仅应用发生变化的项，不覆盖页面上手动调整的其他参数；抓包、检测进行中不改动。
- 设置页“重新打开页面后生效”的提示同步改为“修改后立即生效并自动保存”。

## Changed

- 文档：用户手册 v1.2、设计变更说明 v1.3；README、CLAUDE.md、根目录 `CHANGELOG.md` 随版本更新。

## Known Issues

- 自定义场景模板仍保存在 `user-templates.json`，无图形化编辑器。
- CLI 暂不支持源网卡选择与端口包。
- AI 分析仅支持 DeepSeek。
- 动态 RPC 端口（49152–65535）的可达性无法在“检测远程端口”中验证。
- LDAP 绑定与查询、SQL 登录阶段、WinRM HTTP 阶段无法指定源地址，结果中已注明。
- 编译存在 2 条既有警告：`AppLog.cs(30)` CS8604、`PcapngAnalyzer.cs(90)` CS0168。
- 发布产物未做代码签名，首次运行时 Windows SmartScreen 可能给出警告。
- 尚无安装包工程（MSIX 待代码签名证书就绪后评估）。
