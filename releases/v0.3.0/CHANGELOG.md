# NetFlow v0.3.0

发布日期：2026-09-24

本版本新增实时抓包、端口包、事件日志筛选和 AI 分析，抓包不再依赖同目录的独立宿主程序，界面文案与设置页按专业规范重新整理。

## Added

- **抓包**：主程序以 `--capture-host` 经 UAC 重新启动自身作为抓包进程，单个 exe 即可抓包。
- **抓包**：新增“实时显示”方式（Pktmon 实时模式；同一数据包在多个组件处的重复输出已去重；列表最多 20000 行；不保存文件），与“记录后分析”可选。
- **抓包**：到达最长时长后自动停止并分析。
- **快速测试**：TCP 与 UDP 分开；UDP 123 支持原始 UDP 与 NTP 协议（自动 / 原始 UDP / NTP / 两者）；端口下拉带服务名，含 SQL Server、MySQL、PostgreSQL、Oracle、Redis、MongoDB 等；DNS 可指定服务器；测试完成后默认显示摘要。
- **批量任务**：12 个内置端口包；自定义端口包（新建、覆盖、另存、删除），保存到 SQLite；按“主机 × 端口包”展开；支持停止。
- **事件日志**：中文日志名预置（默认安全日志）；级别、时间范围、事件 ID 筛选；远程查询所需端口提示与“检测远程端口”。
- **AI 分析**：接入 DeepSeek（获取模型列表、推理强度、发送前预览与确认、敏感字段屏蔽、IPv4 占位符与本地还原）。
- **设置**：分组为常规、抓包与分析、数据与隐私、AI 分析、关于与环境；留存清理、输入历史清除。
- **数据**：设置、端口包、最近输入存入 SQLite（schema v2）；API Key 以 DPAPI 加密保存；旧版 `ui-state.json` 一次性导入。
- **文档**：用户手册 v1.0、设计变更说明 v1.1、根目录 `CHANGELOG.md`；README 重写。

## Changed

- 源网卡去除“自动”选项，默认选择带默认网关的以太网卡。
- ICMP（Ping、路径）改用 `IcmpSendEcho2Ex`，按所选源网卡（IPv4）发出。
- SQL Server 场景默认直测 TCP 1433；可指定固定端口或命名实例。
- 界面：表情符号改为 Segoe MDL2 图标；文案与术语按专业规范统一；场景模板名不再带版本号；场景诊断统计卡单行显示；窗口默认 1360 × 860。
- 传输层、协议层及防火墙、服务、网卡状态等枚举值中文化。
- 发布产物：单个 `NetFlow.exe`；ZIP 仅含该文件。

## Fixed

- PowerShell 输出中文乱码（路由、防火墙）。
- 场景诊断结束后顶栏“运行中”指示不消失；抓包页未接入该指示。
- 抓包到达最长时长后不自动结束。
- 实时模式在工作目录遗留最大 512 MB 的 `PktMon.etl`。
- 批量页首次打开时端口包默认落到“不使用端口包”。
- 路由说明重复拼接前缀长度；列表项自动化名称显示为 record 默认文本。

## Known Issues

- 自定义场景模板仍保存在 `user-templates.json`，无图形化编辑器。
- CLI 暂不支持源网卡选择与端口包。
- AI 分析仅支持 DeepSeek。
- 动态 RPC 端口（49152–65535）的可达性无法在“检测远程端口”中验证。
- LDAP 绑定与查询、SQL 登录阶段、WinRM HTTP 阶段无法指定源地址，结果中已注明。
- 编译存在 2 条既有警告：`AppLog.cs(30)` CS8604、`PcapngAnalyzer.cs(90)` CS0168。
- 尚无安装包工程（MSIX 待代码签名证书就绪后评估）。
