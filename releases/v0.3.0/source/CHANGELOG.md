# 变更记录

本文件记录 NetFlow 各正式版本的变更。每个版本的完整快照与发布说明见 `releases/vX.Y.Z/CHANGELOG.md`。版本号遵循语义化版本（MAJOR.MINOR.PATCH）。

## [0.3.0] - 2026-09-24

### 新增

- **抓包**：主程序以 `--capture-host` 经 UAC 重新启动自身作为抓包进程，单个 exe 即可抓包，不再依赖同目录的 `NetFlow.CaptureHost.exe`。
- **抓包**：新增“实时显示”方式（Pktmon 实时模式，去重解析，列表实时追加，不保存文件），与“记录后分析”可选；到达最长时长后自动停止并分析。
- **快速测试**：TCP 与 UDP 分开；UDP 123 支持原始 UDP 与 NTP 协议（自动 / 原始 UDP / NTP / 两者）；端口下拉带服务名，含常见数据库端口；DNS 可指定服务器；测试完成后默认显示摘要，可返回摘要；AI 分析。
- **批量任务**：12 个内置端口包（含“客户端 → AD 域控”）；自定义端口包（新建、覆盖、另存、删除），保存到 SQLite；按“主机 × 端口包”展开，支持停止。
- **事件日志**：中文日志名预置（默认安全日志）；级别、时间范围、事件 ID 筛选（含常用事件 ID 预置）；远程查询所需端口提示与“检测远程端口”。
- **AI 分析**：接入 DeepSeek，支持获取模型列表、推理强度、发送前预览与确认、敏感字段屏蔽、IPv4 占位符与本地还原；快速测试、场景诊断、抓包分析页可用。
- **设置**：分组为常规、抓包与分析、数据与隐私、AI 分析、关于与环境；默认值、留存清理、输入历史清除。
- **数据**：设置、端口包、最近输入统一存入 SQLite（schema v2）；API Key 使用 DPAPI 加密；旧版 `ui-state.json` 一次性导入。
- **源网卡**：默认选择带默认网关的以太网卡；选择被保留。
- **文档**：新增用户手册 v1.0、设计变更说明 v1.1；README 重写。

### 变更

- 源网卡去除“自动”选项，测试必须指定源网卡。
- ICMP（Ping、路径）改用 `IcmpSendEcho2Ex`，按所选源网卡（IPv4）发出。
- SQL Server 场景默认直测 TCP 1433（此前先经 Browser UDP 1434，Browser 关闭时无法测试端口）；可指定端口或命名实例。
- 界面：表情符号改为 Segoe MDL2 图标；文案按专业规范统一，术语统一（源网卡、端口包、检查项、传输层/协议层、证据文件夹等）；场景模板名不再带版本号，版本信息移至列表下方；场景诊断统计卡单行显示；窗口默认 1360 × 860。
- 结果表的传输层、协议层及防火墙、服务、网卡状态等枚举值中文化。

### 修复

- PowerShell 输出按 OEM 代码页解码造成的中文乱码（路由、防火墙）。
- 场景诊断结束后顶栏“运行中”指示不消失；抓包页未接入该指示。
- 抓包到达最长时长后不自动结束。
- 实时模式在工作目录遗留最大 512 MB 的 `PktMon.etl`：现限定在任务目录、最大 16 MB，停止后删除。
- 批量页首次打开时端口包默认落到“不使用端口包”。
- 路由说明重复拼接前缀长度；列表项自动化名称显示为 record 默认文本。

### 已知问题

- 自定义场景模板仍保存在 `user-templates.json`，无图形化编辑器。
- CLI 暂不支持源网卡选择与端口包。
- AI 分析仅支持 DeepSeek。
- 动态 RPC 端口（49152–65535）的可达性无法在“检测远程端口”中验证。
- 编译存在 2 条既有警告：`AppLog.cs(30)` CS8604、`PcapngAnalyzer.cs(90)` CS0168。
- 尚无安装包工程。

## [0.2.0] - 2026-09-24

### 新增

- 顶栏源网卡下拉选择；快速测试、场景诊断、批量任务、持续监测按所选网卡绑定源地址。
- 应用图标（exe、窗口、任务栏）。
- 统一的控件样式、占位提示、空状态引导；总览快速入口直达对应测试类型；历史报告双击打开。

### 变更

- 快速测试先选类型再填参数；抓包、批量、历史、服务、本机网络页布局调整。

### 修复

- ICMP、LDAP、SQL 登录阶段、WinRM HTTP 阶段无法绑定源地址时，不再把请求的源地址写入证据，改为如实注明限制。
- DNS/HTTP 测试被名称预解析拦截；非 TCP/UDP 类型被端口校验拦截；结果表检查项列一律显示 `TcpConnect`。

## [0.1.0] - 2026-09-24

首个可用版本：从填写目标到导出报告的诊断闭环，包含 11 类协议检查、9 个场景模板、Pktmon 抓包、持续监测与离线报告。详见 `releases/v0.1.0/CHANGELOG.md`。
